A.2 Comparing and Ordering Decimals

Compare digit by digit from left to right. For NEGATIVE decimals, the number with the SMALLER absolute value (magnitude) is actually the GREATER number — it's closer to zero.

Worked Example: Which is greater, −0.45 or −0.5?

  • |−0.45| = 0.45 and |−0.5| = 0.5. Since both numbers are negative, the one with the smaller absolute value is greater.
  • Since 0.45 < 0.5, we conclude −0.45 > −0.5.

Example — arranging in increasing order: 1.765, −1.456, −1.82 → −1.82, −1.456, 1.765 (negatives first, most negative to least negative, then positives).

A.3 Addition and Subtraction of Decimals (including negatives)

Use the same rules as for integers: if the signs are the SAME, add the absolute values and keep the sign. If the signs are DIFFERENT, subtract the smaller absolute value from the larger, and keep the sign of the number with the larger absolute value.

To go the other way (fraction → decimal), divide the numerator by the denominator (long division): 7/4 = 1.75, and −9/5 = −1.8.

B — Fractions: Multiplication and Division

Multiplying Fractions

  • No common factors: multiply the numerators together and the denominators together. e.g. 1/2 × 3/5 = (1×3)/(2×5) = 3/10
  • With common factors: cancel common factors between a numerator and a denominator FIRST, then multiply. e.g. 1/4 × 6/7 — cancel 4 and 6 by 2 → 1/2 × 3/7 = 3/14

Dividing Fractions

To divide by a fraction, multiply by its RECIPROCAL (flip the second fraction upside down).

a/b ÷ c/d  =  a/b × d/c

Worked Example: 2/3 ÷ 4/9 = 2/3 × 9/4 — cancel 2&4 by 2, and 3&9 by 3 → 1/1 × 3/2 = 3/2 = 1½

Examples of reading scientific notation aloud: 8.2×10⁹ is read as "8.2 billion"; 5.6×10⁻⁶ is read as "5.6 millionth"; 3.7×10¹² is read as "3.7 trillion"; 4.9×10⁻⁹ is read as "4.9 billionth".

Real-world examples: the world population estimated for 2050 (about 9,800,000,000) is written as 9.8×10⁹. The Bohr radius of a hydrogen atom (0.000000000053 m) is written as 5.3×10⁻¹¹ m.

D.3 Counting Cubes in a 3D Structure

When a structure built from unit cubes is shown as a grid (e.g. the top view, with each number representing how many cubes are stacked at that position), the TOTAL number of cubes in the whole structure is simply the SUM of every number in that one complete grid.

Worked Example: if a top-view grid shows the numbers 3, 2, 1 in one row and 2, 1 in the row below it, the total number of cubes is 3+2+1+2+1 = 9 cubes.
